# Companion Agent Skill

This repository ships the portable agent skill for Physics Nodes Workflow:

- `blender-physics-workflow`: [SKILL.md](blender-physics-workflow/SKILL.md)

To install into an agent skills folder, copy `skills/blender-physics-workflow` into your local skills directory and point `BLENDER_PATH` to your Blender 5.2.1 LTS executable.
