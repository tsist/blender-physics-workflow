# Prototype snapshots — 0.6.0-dev.1

Use Prepare Prototype Copies in the workbench, or operation=prepare_instances with target_object, preset_id=rigid_drop_pack, instance_collection. The UI selects the new collection; CLI returns prepared_instances.prepared_collection. Then explicitly Build / Update using that collection. Preparation never changes existing modifiers or author graphs and cannot bake/export/verify_cold_reopen simultaneously.

The nonempty source must be a flat local static Mesh collection. Parenting, modifiers, constraints, animation/drivers, shape keys, rigid body, nested instances and linked/override data are refused before copying. Every run creates new editable Mesh/Object copies. Effective OBJECT slots become DATA slots; source geometry, slots, basis/delta transforms, UVs and vertex groups are preserved. Native Collection Info instance rows determine fixed-width ordinal names, including natural numbers, mixed case, Unicode and truncated long names. Source data and prior generations are never overwritten. Failures remove only IDs created by the current operation.

The prepared collection has a fake user and survives save/reopen before Build. pnw_prototype_source retains provenance only, not a live dependency. Geometry and slot assignments are independent snapshots; material shader datablocks remain shared. Changing source geometry or slot references does not update the snapshot. Snapshot edits invalidate consumers normally. Material content tuning does not alter geometry cache identity. The new effective-slot signature includes slot order, link, None and material name/library identity; old caches require fresh baking and are retained.

Static output retains the tested per-face materials and UVs. Alembic retains tested material names/face sets and UV maps, not shader graphs/images/render-UV selection. Prepared markers do not bypass export checks: adding unsupported OBJECT overrides later still fails. This feature does not repair physics contact quality or claim overall visual equivalence for unsupported inputs. Hidden/excluded combinations and other Blender versions are unqualified.
